# 🐍 Python Lab Exercises Playground

Welcome to my Python practice repository! This project contains hands-on lab exercises covering fundamental to intermediate Python programming concepts, including control flows, functions, data structures, and string manipulation.

---

## 🛠️ Tech Stack & Tools

* **Language:** Python 3.x
* **Environment:** WSL (Ubuntu) / VS Code
* **Version Control:** Git & GitHub

---

## 📋 Lab Exercises Overview

| Lab # | Module / Subject | Key Concepts Covered |
| :--- | :--- | :--- |
| **Lab 1** | **Smart Survey Onboarding Engine** | `input()`, Type Casting (`int`), Conditionals (`if-elif-else`), `f-strings` |
| **Lab 2** | **Multi-Cluster IP Audit Tool** | Nested Dictionaries (`dict`), Sequential Loops, Percentage Calculations |
| **Lab 3** | **Deployment Budget Optimizer** | Functions with Parameters, `return` values, Budget Logic, Number Formatting |
| **Lab 4** | **Profile Text Normalization** | String Methods (`.strip()`, `.lower()`), List Mutation (`.append()`), Loops |
| **Lab 5** | **System Alert Flag Evaluator** | Complex Boolean Logic (`and`, `or`, `not`), Conditionals, System Telemetry |
